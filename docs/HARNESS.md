# Scholarly KG agent harness

The base system prompt is shipped in the package and hashed into each trace. The agent has a bounded Strata tool loop and hybrid node search. Retrieval loads frozen BM25 and persistent HNSW snapshots; it never builds or encodes documents during queries. The query encoder is Voyage `voyage-4-large`, 1024 dimensions. Each search takes up to ten dense hits and ten BM25 hits, deduplicates by node ID, and sends full frozen corpus text for every candidate to the existing Strata listwise reranker by default, using its validated `reasoning_effort=none` setting. Returned tool text is explicitly capped at 4000 characters per hit; default return count is five, while the reranker always sees the full union. A listwise position is an ordering, not a calibrated probability. `--reranker jev` uses the existing Jev shared-context client and sorts by P(relevant); `--jev-filter` explicitly drops candidates below 0.70 and without the relevant choice. Search returns source metadata and stable IDs. Graph tools can be custom Neo4j, official Neo4j MCP, or both.

Install the `harness` optional dependencies, plus compatible `kg-builder` with its `bm25` and `voyage` extras and persistent dense index support. Set `STRATA_API_KEY`, `VOYAGE_API_KEY`, `NEO4J_URI`, `NEO4J_USERNAME`, and `NEO4J_PASSWORD` in the environment. MCP mode also needs the official `neo4j-mcp` executable and its supported environment settings. No secret is accepted as a CLI argument. For example:

```powershell
python scripts/run_agent.py "Which methods address this research problem?" --run-id RUN --graph-namespace NAMESPACE --bm25-index C:\data\bm25 --dense-index C:\data\hnsw --output-dir C:\data\agent-trace-001 --tool-mode custom
```

The output directory must be new. It is created before runtime initialization, so a setup failure leaves a sanitized `initialization_failed` trace. During a run, `trace.json` is checkpointed after model and tool events, and brief progress events go to stderr. The trace contains the original question, each agent search query, model responses, tool call arguments and results, errors, elapsed times, index identity, runtime discovery, source commit, and prompt hash. The source commit is resolved from the script's repository even when called from another working directory. Secret values are redacted before writing. A budget or malformed model response produces `status: incomplete` with a stop reason and no invented answer. The CLI exits 2 for an incomplete run.

The graph's fixed schema includes nine labels and five relationships; search results by themselves do not establish graph edges. This batch has no optional prompt skills or web tool. Live GPU, service, full-corpus, and paid query-embedding acceptance must be recorded separately from offline tests.
