# Colab Strata deployment

Open [`notebooks/01_strata_colab.ipynb`](../notebooks/01_strata_colab.ipynb) in the supplied Colab runtime and run cells in order. The notebook defaults to the `codex/colab-strata-experiments` GitHub branch. That branch must be pushed before Colab can clone it. It records the resolved commit SHA.

The first manual Colab acceptance used code commit `aff5db417a1aac7ca3b205d4b5dc7c5f8091b5f8`. The user reported five code tests, preflight, and the real smoke check passing. **The successful runtime used port 8081** because 8080 was occupied: change the launch `--port` to `8081` and run `python scripts/strata_smoke.py --base-url http://127.0.0.1:8081`. These are user-reported results; the raw JSON/log artifacts have not yet been independently reviewed. See the stage report for scope and limitations.

This experiment selects **Qwen3.8-Flash-Next, original ISTA-DASLab IQ3_S**, with 32K context, one request slot, text only, and **MTP** drafting. It does not switch model family, quantization or drafter automatically in our code. Strata 0.2.10 is pinned for Terminal installation. Control and engine are separately versioned and must be recorded from the actual run. The notebook keeps data in `/content/strata-data`, artifacts in `/content/strata-artifacts`, and binds the API to localhost with a per-session key.

The model needs roughly 50 GB host RAM for experts plus 10 GB headroom; the documented combined weight memory is 54.8 GB. The first model download is roughly 83.6 GB plus the 5.2 GB MTP layer. The preflight requires 64 GB total RAM, 60 GB available RAM, 40 GB total GPU VRAM, 35 GB free GPU VRAM, and 100 GB free local scratch. These are experiment gates, not Strata compatibility guarantees. The provided A100 80 GB (`sm_80`) is included in the release's Linux CUDA 12 build and omitted from its CUDA 13 build. The selected package still needs checking in the displayed plan and runtime. Do not treat generic NVIDIA support as proof for this exact Colab image.

The notebook runs repository tests **in Colab before model installation**. Then it runs the preflight, installs the pinned Terminal, displays the official `strata launch --plan`, and starts the model in a separate cell. The last cells call `/health`, `/v1/models`, `/props`, `/metrics`, and `/v1/chat/completions`; they verify the actual model path, engine version, 32K context, MTP drafter, a real tool call, and a second turn with the tool result. `/metrics.engine.drafting` must equal `mtp`, since requesting `--drafting mtp` alone does not prove the actual choice. A failure remains visible in `smoke.json` and stops the notebook.

Do not copy weights to Google Drive or load them through the Drive fuse. The final cell downloads a ZIP of small logs and JSON reports. It excludes the session API key and model weights. API evaluation and graph work are separate later phases.
